⚕️ MediSight CDSS – Healthcare Diagnosis Pipeline

MediSight CDSS is an AI-based clinical decision support system designed to predict multiple diseases such as diabetes, heart disease, breast cancer, and kidney disease.
It uses machine learning models like Logistic Regression, Random Forest, and XGBoost for accurate predictions.
The system takes patient clinical inputs and provides real-time risk analysis with probability scores.
Risk levels are classified into Low, Medium, High, and Critical for better understanding.
It also includes data visualization and model performance metrics like accuracy, F1-score, and AUC.
SHAP is used to explain model predictions and highlight important features.
The application is built using Streamlit for an interactive user interface.
This project helps improve early diagnosis and supports better medical decision-making.
